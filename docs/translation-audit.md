# 日本語訳 品質監査レポート

- 対象: 重複除去後の全 172 問（`data/bank.json`）。日本語訳は [`data/i18n/ja.json`](../data/i18n/ja.json) に、問題 ID をキーにして英語データとは別に保存しています（英語データは変更していません）。
- 作成日: 2026-11-08
- 機械チェック: [`scripts/check_translations.py`](../scripts/check_translations.py)（CI でも実行）
- 用語の基準: Microsoft Learn 日本語版（learn.microsoft.com/ja-jp）のページタイトルで確認した表記

## 1. 結論

| 項目 | 結果 |
|---|---|
| 日本語訳がある問題 | **172 / 172 問**（問題文・全選択肢・解説・参照 URL） |
| 翻訳状態 | **要確認 172** / 確認済み 0 / 未翻訳 0 |

すべての訳は AI が作成し、別の AI がチェックしたものです。ユーザーの指示どおり、**AI による自動チェックだけでは「確認済み」にしていません**。全 172 問が「要確認」です。

## 2. 作成方法

1. **翻訳**: AI が、英語原文・品質レビュー時の根拠 URL・用語表をもとに、問題文・選択肢・解説を日本語にしました。
   - Microsoft の製品名・サービス名・API 名・クラス名・パラメーター・コード中の値は英語のまま残しました。
   - 一般概念は Learn 日本語版の表記に合わせました（例: 取得拡張生成 (RAG)、ベクター検索、セマンティック ランキング、マネージド ID、プロビジョニング済みスループット、エバリュエーター）。旧 Azure AI Foundry は「Microsoft Foundry」、旧 Azure AI services は「Foundry Tools」です（[What is Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/what-is-foundry) の対応表で確認）。
   - 日本語解説には「正解の理由」「他の選択肢が適切でない理由」「関連サービスの役割」を書き、Microsoft Learn の参照 URL を付けました。選択肢は画面でシャッフルされるため、A/B/C などの記号では呼んでいません。
   - 公式資料で確認できない説明は推測で補わず、書く場合は「（未検証）」と明示するルールにしました（該当 0 件）。
2. **機械チェック**: `scripts/check_translations.py` で全問題を検査しました（3 章）。
3. **AI クロスチェック**: 翻訳とは別の AI が、英語原文と日本語訳を1問ずつ照合し、必要なら修正しました（4 章）。
4. **翻訳状態**: AI の翻訳と AI のチェックだけのものは「要確認」です。「確認済み」は、人が英語原文と照合した場合だけに設定します（`status: "reviewed"` と `reviewedBy` に確認者を記録。テストで検査）。

### 正答を推測しやすくしていないか

単一選択 142 問で「正解が唯一の最長の選択肢」になっている問題の数を比べました。

| | 英語原文 | 日本語訳 |
|---|---:|---:|
| 正解が唯一の最長の選択肢 | 104 | 102 |

日本語訳で偏りは強まっていません。日本語でだけ正解が最長になった 4 問（q088、q097、q098、q180）は、正解が英語のまま残す製品名・評価器名（Tool Call Accuracy、Azure Content Understanding など）か、カタカナ語のためで、情報を足したものではありません（AI クロスチェックでも確認）。なお、元データ自体の偏り（英語で 104/142）は残っています。

## 5. 人の確認が必要な問題

全 172 問が「要確認」です。特に優先して確認してほしい問題:

**翻訳に自信がない（lowConfidence）**

| ID | 理由 |
|---|---|
| q318 | 原文の "oversight mode" は Learn で確認できる正式な機能名ではなく、「監督モード」と訳した |
| q530 | 誤答肢 "Use only vector top" の意味が不明確（ベクター検索の top-k と推測）。"image seed" も推測で訳した |
| q572 | 正解の "with permissions" が「ユーザー権限を考慮した取得」か「エージェントに付与する権限」か曖昧で、「権限付きの」と直訳した |
| q703 | "structured JSON output" は構造化出力（Structured Outputs）機能とも読めるが、正解は JSON モード（`json_object`）。「構造化された JSON 出力」と一般的な表現にした |

**原文の英語解説に誤りがある**: q701（`DefaultAzureCredential` は ID を作成しない）。日本語解説では正しい内容にしています。

**翻訳メモがある問題**: 47 問。サイトの「問題データ」画面で各問題を開くと「翻訳メモ」として表示されます（例: 評価器名を英語のまま残した理由、Learn 日本語版の表記に合わせた語など）。

## 6. 日本語／英語の切替の確認

`tests/e2e.mjs`（Chrome、幅 360px、タッチ操作）で次を確認しました。

| 確認項目 | 結果 |
|---|---|
| 初期表示が日本語（問題文・選択肢が `data/i18n/ja.json` の訳と一致） | OK |
| 画面上部の「日本語｜EN」を1タップで英語原文に切り替わる | OK |
| 回答中に切り替えても、選択した回答が保たれる（単一選択・ドロップダウン） | OK |
| 切り替えても正誤が変わらない（英語で回答 → 日本語に戻しても「不正解」のまま） | OK |
| 解説も切り替わる（日本語解説 ⇔ 英語原文の解説） | OK |
| 言語設定が localStorage に保存され、再読み込み後も保たれる | OK |
| 日本語・英語とも幅 360px で横スクロールが出ない（日本語は全問題を表示して確認） | OK |
| 分野別学習・模擬試験・復習を日本語で実施できる | OK |

iPhone Safari 向けに、入力・選択要素の文字サイズを 16px 以上にして自動ズームを防ぎ、`viewport-fit=cover` とセーフエリア（`env(safe-area-inset-*)`）に対応しています。選択肢は高さ 56px 以上のタップ領域です。実機の iPhone での確認は、公開後に利用者が行う必要があります。

## 7. 人が確認するときの手順

1. サイトで問題を日本語で表示し、「EN」で英語原文と見比べる（または `data/i18n/ja.json` と `data/bank.json` を比較する）。
2. 問題がなければ、`data/i18n/ja.json` の該当問題の `status` を `"reviewed"` にし、`reviewedBy` に確認者を記録する。誤りがあれば訳を直す。
3. `python3 scripts/build_data.py`、`python3 scripts/check_translations.py`、`npm test` を実行して push する。
